Upload cookies

Any of: Netscape cookies.txt, a JSON export (Cookie-Editor, EditThisCookie), or a Cookie: header string copied from the browser's developer tools on youtube.com.

How to get the file

  1. Use a spare Google account, never your main one. YouTube may suspend accounts used for downloading.
  2. On your computer, open a private / incognito window and sign in to that account on youtube.com.
  3. In the same tab, go to https://www.youtube.com/robots.txt.
  4. Export the cookies for youtube.com with a cookies.txt extension (for example “Get cookies.txt LOCALLY”; allow it in private windows), then close the private window right away. If you keep browsing with that session, YouTube rotates the cookies and the file stops working.
    Without an extension: in that tab open developer tools → Network, reload, click the first request to www.youtube.com and copy the whole cookie: request header (not document.cookie, which misses the important login cookies).
  5. Upload the file here and press Test now. The file is stored only on your server (readable by the app only).

Cookies last weeks to months. When downloads start failing with the bot message again, the “Needs attention” banner (and your phone alert, if set up) will say so: export a fresh file the same way.
