# Security policy

PrivaTube guards private content on servers that face the internet, so security reports
are very welcome.

Please **don't open a public issue** for a vulnerability. Use GitHub's
**"Report a vulnerability"** button (Security tab → Advisories) to report it privately.
Include the steps to reproduce it and what an attacker could gain.

Only the latest release is supported. Fixes are released as soon as they are ready, and
the advisory is published afterwards with credit to you, if you like.
